# Rushikesh Sawale Portfolio

Complete responsive multi-page static portfolio.

## Pages

Home, About, Skills, Projects, Experience, Services and Contact.

## Project management

All five major project cards are generated from `data/projects.js`. Add/delete/modify one object there; `projects.html` does not need duplicated card HTML.

## Major projects

1. IntelliFlow: AI-Based Multi-Intersection Traffic Signal Coordination System
2. AI-Powered Trading Decision Support Platform
3. Business Management System
4. FarmGuard: Smart Remote Farm Pump Monitoring, Control & Safety System
5. ValidatorAI

## Assets

Copy your existing `profilepic.jpg` to `assets/images/profile/profilepic.jpg`. Copy your resume to `assets/resume/Rushikesh_Sawale_VITP.pdf`. Add project screenshots under `assets/images/projects/` when available.

## Run

Open `index.html` directly or use VS Code Live Server.
